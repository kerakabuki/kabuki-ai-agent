## 一枚で言うと

地下ホールで「浜松屋」短縮版（40分前後の見込み）、幕間30分（客の飲食の時間。裏では着替え）で客を屋外へ移して火入れ、岩の舞台の前でかがり火の中の「稲瀬川勢揃い」。芝居あわせて約60分、前後を入れて夜全体で約105分。薪能のように火の中で歌舞伎を観る趣向。客は30〜40名の合同回。郡上から動くのは10人。

## 演目の形

**浜松屋（短縮版 v1、目安40分前後）**
- 底本は黙阿弥全集第4巻の原文。気良の2020年配信版の構成を文字起こしで確認し、名乗りの前後は一行も切らず、役者噺・鳶頭の顔貸し・名乗り後の金のやりとり・花道の小芝居を刈った
- 肌脱ぎの後の「体中痛え」の小芝居は、舞台上の着替えの時間を埋めるものなので残す（3分）
- 幸兵衛は出さない。倅宗之助が「父は他行中で留守を預かる若旦那」として、詫びも百両も膏薬代も払う。台詞は若旦那らしく柔らかく直してある
- 鳶頭清次は原文どおり出す。騒ぎの先頭に立ち、「顔を貸して」の十両の談判をする（七人版で一分戻した）
- 英語字幕を出す箇所を【超訳】、下座の音源キューを【音】で台本に入れてある

**稲瀬川（令和7年台本のまま）**
- 道行の唄、七五の渡り台詞、捕手の声、名乗り、「からめてみよ／それ」でツケと見得、幕の代わりに一礼と写真
- 立ち廻りはなし。捕手は番頭と手代の2人。捕手の台詞（短い5本）は二人で分ける。「して真っ先に進みしは」は客の「Name yourselves!」に置き換え可
- 土手は作らない。屋外舞台の段差を土手に見立て、五人が舞台前縁に並び捕手が下。かがり火を客席と舞台の間に置くと、火越しに見上げる形になって高低差が大きく見える。段差が足りなければ気良座の平台を2〜3枚持ち込む

## 衣裳・鬘・化粧（川上衣装）

- 浜松屋7組、稲瀬川の揃い5組、捕手2組、合わせて14組。弁天の肌脱ぎ用に彫り物の肉襦袢

## 音と字幕

- 音は録音の再生。稲瀬川は台本の音源キュー（唄①②③）、浜松屋は2020年の自主公演の録音から作る（権利は自前）。唄の入る出入りは原音を切り出し、台詞の下の合方だけ人声抜きの音源を使う二段構え。曽根崎で同じ道具を使っている
- 生演奏を客が希望する場合は別払いのオプション（演奏者の謝礼と交通は縄山茶屋から直接）
- 英語字幕は地下ホールの大型モニターに。屋外は投影かボードか要検討。前説の素材は2018年の対訳スライド（見得、大向う、おひねり、立役と女形、隈取）と稲瀬川の英語リーフレット（「渡り台詞はスーパー戦隊、つまりパワーレンジャーの名乗りの元」の一行をそのまま使う）

## 雨天の形

- 判断は当日午前。客への連絡は縄山茶屋
- 浜松屋の後、そのまま地下ホールに残って稲瀬川。演目も衣裳も変えない
- 傘は天井高に応じて、低く構えるか持つだけにする（舞台上で3.5mあれば傘も見得も可、3m前後なら低く構える、2.5mなら傘は無理）
- 火入れの代わりに「灯入れ」。既設のLEDを火の色に落としてから五人が出る
- 終わりは暗転で五人が引っ込み、明かりを戻して一礼と大向う、写真
- 地下版も最初から一つの形として稽古しておく

## 昼の回（2026-10-15 追記）

昼夜どちらでも対応可。浜松屋（地下ホール）は変わらず、屋外の稲瀬川だけ次が変わる。

| | 夜（薪歌舞伎） | 昼 |
|---|---|---|
| 売り | かがり火の中の五人男 | 岩を背にした五人の傘。写真は明るい |
| 土手 | 火越しに見上げる形で段差で足りる | 段差が浅ければ平台を2〜3枚持ち込む |
| 幕間の見せ場 | 火入れ | 隈取の実演と客参加で埋める |
| 字幕 | 投影かモニター | モニターかボード（日中は投影が効かない） |
| 季節 | 春秋の夜 | 冬以外ほぼ通年。日帰り客に組みやすい |

名前は「薪歌舞伎」を夜の回だけに使い、昼は「白浪五人男 通し」と呼ぶ。

## 費用の考え方

- 出演料と個人への謝礼は取らない。気良へは交通費と当日の飲食の実費のみ
- 川上衣装へは縄山茶屋から直接。生演奏を付ける場合の演奏者も直接
- 1回あたりの原価の目安は川上衣装の見積が戻り次第。現時点の見込みは【80〜120万円】前後
- 名称「薪歌舞伎」は気良歌舞伎の公演名。縄山茶屋での開催はその出張公演

## 縄山茶屋に確認すること

1. 地下ホールの舞台上の天井高（傘の構えを決める）、舞台の間口と奥行、ピアノを動かせるか
2. 屋外舞台の段差の高さ（舞台面と客席の土間の差。土手の代わりになるか）
3. 雨天時の判断の時刻と連絡の流れ
4. 搬入口と駐車（車2〜3台、衣裳と道具）
5. 屋外の字幕をどう出すか（投影、モニター、ボード）
6. 擬岩に上ってよいか（将来の鳴神の検討のため）
