## 2. ジャンル内での立ち位置（調査①より）

地歌舞伎ジャンルのデジタル発信は**全体的に極めて薄い**。

- **保存会・座own の公式YouTubeチャンネルで登録者実数を確認できたものは1件もなかった**。公演映像は県のポータルか個人愛好家によるアップロードが中心
- Instagramで確認できた実数：かしも明治座（施設）1,315人／中山農村歌舞伎保存会（小豆島）134人／尾瀬檜枝岐温泉観光協会（村の観光アカウント）8,939人
- note・TikTokはほぼ空白。TikTokは地歌舞伎団体のアカウントを1件も発見できず

→ **登録者1,050人・130本・人気動画5.5万回という気良歌舞伎の規模は、このジャンルでは頭ひとつ抜けている可能性が高い**（調査は網羅的でないため断定はしない）。

**つまり「これから発信を始める」段階ではない。既に勝っている場所があり、それを自覚できていなかった、というのが現状の正確な記述。**

## 3. 決定的な発見 ―― いま来ている人は「気良歌舞伎」を探していない

外部監査（調査④）と YouTube 実データを突き合わせると、はっきりした像が出る。

| 事実 | 出所 |
|---|---|
| 「気良歌舞伎」「気良座」「けら歌舞伎」「KABUKI PLUS+」「けらのすけ」で検索しても、ほぼ何も出てこない | 調査④ 実検索 |
| 一方で、演目名＋名台詞の動画は5.5万回・3.5万回・1.9万回再生されている | YouTube実データ |

**団体名での認知はほぼゼロ。にもかかわらず十数万回見られている。**
入口になっているのは団体名ではなく、**「知らざあ言って聞かせやしょう」「しがねえ恋の情けが仇」といった名台詞・演目名の検索**。

5.5万回見た人は気良歌舞伎を探して来たのではない。**歌舞伎を無料でフルで観たくて来た。** そこにたまたま気良歌舞伎があった。

### さらに: 差を生んでいるのは「切り方」ではなく「演目の検索需要」

当初「全編2時間半（287回）が伸びないのは切り方の問題で、演目単位に切れば伸びる」と考えたが、**実際には演目単位のアップロードは既に存在し、それも数百回にとどまっていた**。仮説は成立しない。

**同一シリーズ・同一時期で比較すると、差は演目そのものから来ている（2026-08-15 取得）**

| 動画 | 投稿 | 再生数 |
|---|---|---|

| 【5分でわかる】封印切（超訳！歌舞伎ナビ） | 7か月前 | **254回** |

**同じ解説シリーズで100倍以上の差。** 尺も作りも同じなので、違いは**演目の知名度＝検索需要**しかない。

### 結論：再生数を決めているのは演目選定であって、映像の質でも切り方でもない

→ **「どの演目のアーカイブを、どのタイトルで出すか」が最大のマーケティング変数。** 20年分のアーカイブは「順番に出す」のではなく、**検索需要の大きい演目から出す**。

### 注意：外から見えるのは累計再生数だけ

浜松屋の5.5万回が「公開直後に伸びた」のか「5年かけて検索でじわじわ積んだ」のかは、外部からは判別できない。**打ち手が正反対になるため、この判別が最優先**（→ §7）。

## 4. ポジショニングの結論

### 取るべき位置

> **「歌舞伎を、無料で・通しで・わかるように観られる場所」。**
> **地歌舞伎の一座としての認知は、その入口を通った人に二段目で渡す。**

理由：

1. **既にそこで勝っている**。1,050人・十数万回再生は全部この構造で取れている
2. **ジャンルに競合がいない**。保存会で公式チャンネルを継続運用している例が確認できない。無料でフル公開している座はさらに少ない
3. **団体名から入る導線は、6週間では作れない**。検索で何も出ない状態を反転させるのは年単位の仕事。演目名からの流入は今日から効く
4. 調査②の示唆（「制度」より「人」が動く／團十郎個人120万 vs 松竹公式3.9万）とも矛盾しない。**ただし気良の場合、人物に行く前に「演目」という既に開いている入口がある。順番は 演目 → 座 → 人**

### 捨てる位置

- **「岐阜の地歌舞伎団体のひとつ」という位置は取らない。** 岐阜県は「地芝居大国」を掲げ40超の団体が現存する。その中の1つとして並ぶと埋もれる。県のポータルに載ることは狙うが、そこを主戦場にしない
- **「伝統を守る保存会」という自己紹介から入らない。** 検索されていない。誰も探していない言葉

### 曽根崎心中との接続（ここが今年の勝負どころ）

- 調査④：「曽根崎心中 2026 公演」で検索すると**南座（2026年3月）とシネマ歌舞伎（2026年4月）が独占**。演目名だけでは大歌舞伎に埋没する
- しかし気良の実績は「**演目名＋名台詞**」での流入。曽根崎心中の名台詞は **「この世のなごり、夜もなごり」**
- そして調べた範囲では、**地芝居での『曽根崎心中』上演記録は見つかっていない**＝公演後の映像には競合が存在しない

**→ 今年の本丸は、9/26の客席ではなく「地芝居で唯一の『曽根崎心中』全編映像」という恒久資産を作ること。** 公演当日は、その素材を撮る日でもある。

## 5. 媒体別の運用方針

### 5-1. YouTube ―― 主戦場。ここに資源を集中する

**① アーカイブは「検索需要の大きい演目」から出す（最優先）**

演目単位の切り出しは既にやっている。足りないのは切り方ではなく**演目の選び方**。20年分のアーカイブを順に出すのではなく、**検索需要の大きい順**に並べ替える。

需要が大きいと見込める演目（気良の実績＋一般的な知名度から）：

| 優先 | 演目 | 根拠 |
|---|---|---|
| 高 | 白浪五人男／弁天小僧（浜松屋・稲瀬川） | 気良の実績で5.5万・1.6万 |
| 高 | 仮名手本忠臣蔵（特に七段目・六段目・三段目） | 知名度最上位。気良は平成18・19・26年ほか多数所蔵 |
| 高 | 切られ与三（源氏店） | 実績1.9万 |
| 中 | 義経千本桜／勧進帳／菅原伝授手習鑑 寺子屋 | 一般知名度が高い。寺子屋は所蔵あり |
| 中 | 絵本太功記十段目／熊谷陣屋／盛綱陣屋／先代萩 | 中程度 |
| 低 | 封印切／寿曽我対面／伊勢音頭／箱根霊験 | 実績で数百回 |

**タイトルは名台詞を必ず入れる**（`【演目名】場の名前｜「名台詞」｜作品名 歌舞伎`）。伸びた動画は全部この型。同じ演目の別年度公演も、別動画として出す価値がある。

**② 曽根崎心中PVを公開する（試作済み・未公開）**

公演前の告知動画には**1,118回**という実績がある（前年の襲名披露告知）。曽根崎心中PVは `pv_sonezaki_r8.json` で試作済みのまま眠っている。**9/26までに出す。**

**③ 曽根崎心中の解説動画（公開済み・212回）は「仕込み」と捉える**

既にアップ済み（1か月前・4:50・212回）。浜松屋が5年かけて5.5万に達している可能性を考えると、1か月で評価するのは早すぎる。ただし**タイトルのシリーズ名が「【超訳！歌舞伎ナビ】」で、3.5万回を取った動画の「【わかる！超訳】」と異なる**。シリーズ名の統一は検討の余地がある（ただし後述のとおり、シリーズ名より演目需要の方が支配的なので優先度は低い）。

**④ 公演後：曽根崎心中の全編を演目単位で公開（最重要の恒久資産）**

競合ゼロの検索領域を取れる。**9/26の記録撮影の質が、この資産の質を決める。**当日の撮影計画（引き・寄せ・音）はPRの一部として扱うこと。

**④ Shorts は補助**

主軸ではない。長尺への導線として使う。調査③より、Shorts→長尺の転換は自動では起きず**CTAで明示的に橋渡ししないと機能しない**。実写の見得カットは有効だが、Shortsを増やすことより①〜③が先。

**⑤ AI生成コンテンツの注意（調査③）**

YouTubeは2025年7月に「反復コンテンツ」を「**非本物のコンテンツ**」ポリシーへ改称・厳格化。読み上げ音声＋静止画スライドの量産動画が対象。けらのすけナレーション＋生成画像の解説動画は形式上そこに近い。
- 開示義務の対象は「実在の人物・出来事と見紛う合成」のみ。TTSナレーションや台本生成は**開示不要**（YouTube公式ヘルプ）
- リスク低減は「量産に見せないこと」。**近松原文の翻刻・一次資料・自前の公演映像という独自性が、そのまま防御になっている**。生成画像だけで構成された動画を連発しない

### 5-2. Instagram ―― 旧アカウントはログイン不能。移行前提で組む

**現状：633人の旧 @kerakabuki は運営者がログインできない状態**（2026-08-15 確認）。約9.5か月更新が止まって見えるのはこれが原因と考えられる。@kerakabuki_official（240人）が新設され、post-365の自動投稿はそちらに流れている。

したがって「旧アカウントのプロフィールを更新する」「自動投稿の宛先を633人側に切り替える」はいずれも**選択肢として存在しない**。復旧を試みつつ、**復旧しない前提で移行を進める**。

**① 復旧の試み（運営者本人がMetaの正規フローで実施する）**

原因ごとに経路が違うので、まず切り分ける。**登録メールアドレス・電話番号が誰のものか（座員の誰かが作った可能性を含む）の特定が最初。**

| 状況 | 経路 |
|---|---|
| パスワード忘れ・登録メール/電話は使える | ログイン画面の「パスワードを忘れた場合」から再設定 |
| 2段階認証の端末を紛失 | バックアップコード → 無い場合は「別の方法を試す」 |
| 登録メール/電話にアクセスできない | 動画セルフィー認証（本人確認）フロー |
| **Facebookページと連携していた場合** | **Meta Business Suite / アカウントセンター経由で管理権限が生きている可能性がある。ここが最も現実的な突破口** |
| 乗っ取り・凍結 | instagram.com/hacked |

> ⚠️ 認証情報の入力・本人確認は必ず運営者本人が行う。AIエージェントに認証情報を渡さない。

**② 復旧しない前提の移行（こちらを主線で進める）**

旧アカウントは削除もできないため、**633人は「取り戻す」より「積み直す」方が早い**可能性が高い。

- **YouTube概要欄・note・kabukiplus.com・linktr.ee のIGリンクを全部 @kerakabuki_official に張り替える**（旧アカウントを指しているものが残っていないか総点検）
- 本人・座員の個人アカウントから「公式は @kerakabuki_official です」と告知＋タグ付け。旧アカウントのフォロワーと座員のフォロワーは重なっているはずで、ここが唯一の移行導線
- **9/26公演当日が最大のフォロワー獲得機会**。会場にQRコード（受付・プログラム・掲示）を置く。遠征客も来ている座なので、来場者からの新規獲得は現実的
- 旧アカウントのプロフィールはYouTubeチャンネルを指したまま残る。**主戦場がYouTubeである以上、放置しても致命傷ではない**（むしろ看板としては機能し続ける）

**③ 確認しておくこと**

- 旧アカウントが**乗っ取られていないか**（第三者が投稿していないか）。単なるログイン不能なら実害は小さいが、乗っ取りなら名義を騙られるリスクがあるので優先度が上がる

**運用の方針転換（調査③より）**

- Mosseri氏が「**sends per reach（DM送信率）**」を最重要シグナルの一つと明言。DM送信はいいねの3〜5倍の重み
- **ハッシュタグはリーチを直接押し上げない**とも本人が明言（検索・分類用途）

→ 現行の「ハッシュタグ8〜12個＋いいね狙いの文体」は前提が古い。**「人に送りたくなる情報密度」**へ設計変更する。具体的には、告知は1枚絵ではなくカルーセルで情報を完結させ（日時・会場・アクセス・演目・入場無料が1投稿で分かる）、**「これ送っとくわ」で友人に転送される形**にする。ハッシュタグは削減してよい。

**運用の方針転換（調査③より）**

- Mosseri氏が「**sends per reach（DM送信率）**」を最重要シグナルの一つと明言。DM送信はいいねの3〜5倍の重み
- **ハッシュタグはリーチを直接押し上げない**とも本人が明言（検索・分類用途）

→ 現行の「ハッシュタグ8〜12個＋いいね狙いの文体」は前提が古い。**「人に送りたくなる情報密度」**へ設計変更する。具体的には、告知は1枚絵ではなくカルーセルで情報を完結させ（日時・会場・アクセス・演目・入場無料が1投稿で分かる）、**「これ送っとくわ」で友人に転送される形**にする。ハッシュタグは削減してよい。

**期待値は下げてよい。** この座の主戦場はYouTubeであって、IGは地元・既存ファン向けの連絡板に近い。日次自動投稿は継続の担保として回し続けるが、ここでリーチを取ろうとしない。

### 5-3. note ―― 長期資産。集客装置とは見ない

調査③より、noteは**生成AI経由の流入が2025年1〜8月で約3倍に増加**、長文記事が時間差で読まれ続ける特性がある。曽根崎心中の研究連載（近松原文の翻刻・辛崎心中の連鎖）を置く場所として妥当。

- **記者・研究者・歌舞伎好きへの信用形成**に使う。プレスリリースの裏付けとしても機能する
- ただし**これで客席が埋まるとは考えない**。読者と来場者は重ならない
- 調査①より **note は地歌舞伎ジャンルでほぼ空白**。気良歌舞伎自身のnoteが目立つほど先行事例が薄い＝ここも取れている位置

### 5-4. Bluesky ―― 現状維持

自動投稿で回っており追加コストがゼロ。定量的な実力は調査で確定できず（信頼できる一次数値なし）。**判断材料が出るまで放置でよい。**

### 5-5. X ―― 見送り確定

X APIは**2026年2月に無料枠を完全廃止、従量課金へ移行**（新規で月額プラン購入も不可）。無料での自動投稿再開という選択肢が存在しない。再開は有料前提の経営判断になるため、今年は見送る。

### 5-6. TikTok ―― やらない

調査①で地歌舞伎団体のアカウントを1件も発見できず、調査③でも自治体の成功事例はすべて予算投下型タイアップ。1人運用で見合わない。

### 5-7. Facebook ―― 大型告知のみ人力（変更なし）

7月の実測（API日次投稿＝配信0% / 人力ポスター＝915閲覧・シェア経由71%）どおり。9月上旬・9/19・9/25の3回、人力投稿＋座員の個人シェア。

### 5-8. 導線の一本化 ―― 3系統に分散している

`kerakabuki.jimdofree.com`（YouTubeのリンク先）／`linktr.ee/kerakabuki`（IGのリンク先）／`kabukiplus.com`（自社開発）が並立している。訪問者がどこで公演情報に行き着くかが運任せになっている。

**最低限、3つすべてに9/26の情報（日時・会場・演目・入場無料）が載っている状態にする。** 統合するかは公演後の課題。

### 参考にすべき3チャンネル

**① 歌舞伎YouTuber 電脳和風（4,710人）── 「定期フォーマット」の教科書**

毎月の歌舞伎座公演を「本音ネタバレ ランキング1〜3位／4〜6位」の形で必ず出す。20分前後のトーク、各回2,000〜4,800回。最高は『もののけ姫』歌舞伎の1.2万回（時事ネタ）。

- **タイトルの型が完全に固定**（`【本音ネタバレ ○月歌舞伎座ランキング 1〜3位】`）。次に何が来るか分かるから登録される
- 登録者4,710人に対し毎回2,000〜4,000回＝**登録者の半分近くが毎回観ている**
- 気良への転用：**「毎月必ず出るもの」を1本決める**。【わかる！超訳】を月1本、演目を変えて必ず出すのが最も現実的

**② カブキカフェナゴヤ座（3,430人・動画975本）── 「一座の日常」モデル**

「一座の日常」というシリーズを**230回以上・メンバー限定**で継続。YouTubeメンバーシップ（月額課金）で舞台裏を出し続けている。リーチ最大化ではなく、熱心なファンの深堀りと収益化のモデル。

- **構造が気良に最も近い**（常設の小屋を持つ非プロの一座）
- 気良への転用：**【素人役者紀行】（33回・38回）が既にこの芽**。数字が小さいのは当然で、これは「広く当てる」ものではなく「登録者を離さない」もの。**評価軸を分ける**
