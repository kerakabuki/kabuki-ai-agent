## 2. 診断 — 何が詰まっているか

### (A) 在庫過多・出荷不足

作る力は自動化で十分に足りている。詰まっているのは全部その先。

- 20年分の映像 → ショートに変換されていない
- 15,541枚の写真 → 1%しか使われていない
- 聖地連載7本 → 全部 draft のまま3か月
- 決定版紹介動画 → 台本で止まって2週間

**新しく作るより、既にあるものを出す方が圧倒的に投資対効果が高い局面にいる。** 6週間しかない今はなおさら。

### (B) 公開台帳がない

`status: draft` のまま公開済みの記事があり、frontmatter が実態を反映していない。「何がどこに公開済みで、どこにリンクが張ってあるか」を一覧できる場所がリポジトリにもどこにもない。

これは地味に見えて実害が大きい。**公演告知の追記漏れ（演目解説記事に9/26の記載がない）はこれが原因。** 導線を張るべき既存資産を、張り忘れたまま気づけない。

### (C) リーチの実測と施策がずれている

手元にある唯一の硬い数字（2026-07 Facebookインサイト）:

| | 閲覧 | フォロワー外 | 反応 |
|---|---|---|---|
| API日次自動投稿（7/6） | 12 | **配信0%** | 0 |
| 人力ポスター告知（7/5） | **915** | 71%（シェア4件経由） | いいね33・コメント9・フォロー+1 |

読み取れること: **リーチを生んだのは「投稿の本数」ではなく「シェアされる1枚」だった。** 76倍の差が出ている。

にもかかわらず、いま人の手が入っているのは日次自動投稿の側。**シェアされる1枚をいつ・何枚出すかが誰の担当にもなっていない。**

### (D) 目的が2つ混ざっている

- **A：9/26の客席を埋める** — 期限あり。地理的制約あり。届け先は岐阜県内＋歌舞伎の遠征層
- **B：気良歌舞伎という名前を資産にする** — 期限なし。届け先は全国。後継者・支援・将来の観客・取材につながる

この2つは施策も評価指標も違う。混ぜたまま「PRを頑張る」と、両方に中途半端に効く施策ばかりが残る。**以下は明示的に分ける。**

### (E) 客席の流入経路を一度も測っていない

`story-video-script-01.md` に、開演5時間前に埼玉から来場、芳名帳に東京・名古屋・新潟・金沢、開演前に満席・立ち見という記述がある。**つまり遠征客は実際に来ている。**

しかし「その人たちが何で気良歌舞伎を知ったか」のデータがゼロ。これがないと、来年以降も勘でPRし続けることになる。**当日アンケート1問で解決する**（後述）。

## 3. 6週間の設計（8/14 → 9/26）

### ゴールA：9/26の客席

**効く順に並べると、SNSは3番目以降。**

#### A-1. プレスリリース ―― 最優先・8月中に投函（★最大のレバレッジ）

新聞1本で地元に届く数は、6週間SNSを回して届く数より確実に多い。しかも無料。

**送付先**

| 先 | 窓口 |
|---|---|
| 岐阜新聞（郡上通信部／文化部） | 地域面＋文化面の両狙い |
| 中日新聞（郡上支局） | 同上 |
| NHK岐阜放送局 | 夕方のローカルニュース枠 |
| ぎふチャン（岐阜放送） | 情報番組 |
| 郡上市 広報担当・明宝振興事務所 | 市広報誌・市公式SNS |
| 郡上市観光連盟／明宝観光協会 | 観光サイト・イベントカレンダー |
| 岐阜県 地歌舞伎関係窓口（清流の国ぎふ 地歌舞伎） | 県の地歌舞伎ポータル |

**リリースの核（記者が見出しを書ける材料を3つ渡す）**

1. **映画『国宝』のあの演目に、郡上の山里の地芝居が挑む** ―― 記者が読者に説明しやすい。時事フックとして今年しか使えない
2. **地芝居での『曽根崎心中』上演記録は、調べた範囲では見つからない** ―― 「おそらく極めて珍しい」と書ける。※断定表現は使わない。裏付けとして `research/sonezaki/sonezaki-jishibai-precedent.md` の調査経緯を添付できる
3. **お初徳兵衛を二組で演じる「配役リレー」。結末の第三場は若手が初挑戦** ―― 世代継承。写真が撮れる。人間の物語になる

**添付すべきもの**（これがあると採用率が跳ね上がる）

- 稽古写真（横位置・高解像度・数点）
- 昭和15年の手彩色画／昭和25年の写真 ―― **「85年前から続く」の絵的な証拠。文化面の記者はこれで書ける**
- 近松原文の翻刻・研究連載note ―― 「素人一座がここまで調べている」という取材動機

> 📌 リリース文面は未作成。8月中に作る。`writer` エージェントで下書き→本人推敲。

#### A-2. シェアされる1枚（実測で唯一効いている施策）

- **9月上旬に1回**（ポスター解禁・配役リレー図・日時会場入り）
- **9/19前後に1回**（あと1週間）
- **9/25**（前日）

いずれも **Facebook人力投稿 → 本人と座員の個人アカウントでシェア** をセットで。API投稿は使わない。座員へのシェア依頼は口頭で回すこと（依頼しないと起きない）。
公演前の少額ブースト（数千円）を9月上旬の1枚に限って試すのは合理的。

#### A-3. 地元のオフライン導線

SNSに乗らない層に確実に届く経路。コストほぼゼロ。

- 明宝・郡上市内の掲示板・道の駅（明宝）・温泉施設・商工会
- 市広報誌のイベント欄（締切が早いので**今週中に確認**）
- 郡上市内の学校・公民館
- 過去公演の芳名帳・来場者名簿 → 案内はがき or メール（**リピーターは最も確度が高い層**）

#### A-4. SNS（土台として維持、上乗せは最小限）

kabuki-post-365 の日次投稿は現状のまま回す。上乗せするのは公演連動の差し込みだけ:

| 時期 | 差し込み |

**心中演目なので、AI生成文は必ず目視レビューしてから approved。** カウントダウンも品位を保つ。

### ゴールB：気良歌舞伎の名前を資産にする

#### B-1. YouTube Shorts ―― 在庫放出モードに切り替える

**週1〜2本。ネタは20年分のアーカイブから。** 公演告知色をつけない回を必ず混ぜる。

冷たい視聴者に効くフックは「田舎の素人が本気で歌舞伎をやっている」という事実そのもの。**実写でしか出せない。** イラストは「歌舞伎の解説」という競合だらけの枠に自分から入ってしまう。

制作の波と投稿の波を分ける ―― **半日かけてカットをまとめて抜き、ストックから1本ずつ出す。** 制作が止まっても投稿が止まらない状態を作る。

出す順の目安:

1. 実写PV（JA/EN）※試作済み。**保存先を決めて公開するだけ**
2. 襲名披露公演・こけら落としの見得カット（数本分ストック可能）
3. 昭和15年／昭和25年の史料 →「85年前の気良歌舞伎」1本（**これは伸びる可能性が高い。他にない絵**）
4. 配役リレー（8月下旬・ここで初めて9/26を前面に）
5. 公演後：本番実写のハイライト（**「言った通り本気でやった」の証明。ここが一番強い**）

#### B-2. note ―― 在庫を出し切る

| 時期 | 出すもの | 狙い |
|---|---|---|
| 8月中 | 研究連載の残り（第4回・第5回） | 記者・歌舞伎好き・研究者への信用形成。**プレスリリースの前に出ていると効く** |
| 9月上旬 | **聖地連載 第4回（曽根崎心中／生國魂神社・お初天神）** | 予習記事として公演直結。draft のまま眠らせるのは損 |
| 9月上旬 | 演目解説記事に**公演告知を追記**（3/7公開分） | 検索流入が既にある記事に導線を張る。工数最小・効果確実 |
| 10月 | 公演レポート → `/import-column` で KABUKI PLUS+ へ | 資産化 |

**AI黒衣記事は10月以降に回す**のが良い。9月は公演の軸を1本に絞るべきで、KABUKI PLUS+ の話は別軸として独立させた方が両方生きる。

#### B-3. 決定版紹介動画（13分30秒）

**公演後に制作するのが正しい。** 9/26が終わると、こけら落とし → 襲名披露 → 曽根崎心中初演 という三段の物語が完結する。いま作ると結末がない状態で出すことになる。台本はそのままで、第5章「あかりは、まだ見ぬ舞台へ」に9/26を入れられる。
