## 三つの形に共通して伺いたいこと

1. 大垣（縄山茶屋）への出張費
2. 顔師、床山、着付けの人数と、拘束時間（開演前の支度から幕間まで）
3. 客への隈取（4〜8名）。材料費、1人何分か、化粧落としまで含むか
4. 彫り物の肉襦袢の有無
5. 捕手の黒衣裳を川上衣装で揃える場合の額（傘と十手は気良で用意）
6. 3か月前の日程確定で受けていただけるか。確定後のキャンセル規定
7. 昼の開催と夜の開催（現時点では未定）、雨天で地下ホールに移る場合で、額や段取りに違いがあるか
8. 年に2回程度を予定した場合の回数割引の有無
