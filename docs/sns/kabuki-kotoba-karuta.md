# 気良歌舞伎かるた　読み札案（歌舞伎から生まれた言葉×日常）

- 作成日：2026-09-30
- 目的：気良歌舞伎 Instagram の毎日投稿用。歌舞伎から生まれて今も使われている言葉を1枚ずつ取り上げ、その「今の意味」で日常のひとコマを詠む。クスっと笑ったあと、札の下の由来（サイト掲載文）で「もとは歌舞伎の言葉だったのか」と知ってもらう。
- ルール要約：5・7・5（小さい「ゃゅょぁぃぅぇぉ」は前の字と合わせて1音、「っ」「ん」「ー」は1音）。字余り・字足らずなし。その言葉を必ず入れ、なるべく句の頭に置く。長い言葉は句をまたいでよい（その場合は案の横に「句またがり」と書き、よみは5・7・5で機械的に区切っている）。言葉の並びは `src/yurai_page.js` の順。
- 避けたもの：人の死・心中・切腹・病気の笑い、見た目・性別・年齢・職業で人を下げる笑い、下品な言葉、政治、企業名・商品名、実在の座員を事実のように書くこと。「大根役者」は自分たちの自虐の方向で詠んでいる。
- 「（試作）」とある案は、試作で使った3枚。
- 選び方：いいと思う案の □ を ■ にする

※生成した案です。公開前に人の目で確認してください。

## まず出すなら（おすすめ10枚）

日常の「あるある」が強く、気良らしさも出ているもの。最初の2〜3週はここから出すと、シリーズの色が伝わりやすい。

1. 捨て台詞／言って戻って／傘を取る（24）
2. 黒幕は／犬を太らす／ばあちゃんだ（14）
3. 裏方の／母のおにぎり／主役級（4）
4. 修羅場です／朝の七時の／洗面所（20）
5. 十八番だと／言うわりに父／歌詞を見る（22）
6. 花道を／飾ったはずが／再雇用（39）
7. 見得を切る／父の「任せろ」／棚ゆがむ（43）
8. 日焼け顔／檜舞台に／白く塗る（46）
9. 大根役者／畑では／当たり年（9。一座の自虐として使ってよいか確認）
10. ドロンした／はずが靴だけ／残ってる（32）

**使う前に判断が要るもの**
- **世話女房（25）**：言葉そのものが「夫の世話を焼く妻」という意味なので、使うかどうかを決める。使うなら、案1（五歳の子がまねをする）がいちばん角が立たない。
- **大根役者（9）**：一座の自虐として笑ってよいか、一座で確認する。
- **句またがりの札（一枚看板・大根役者・世話女房・千両役者・どんでん返し・のべつ幕なし・こけら落とし・てんてこまい・市松模様の案2）**：カードでは言葉の切れ目で改行して見せる（例：「一枚看板／わが家は犬の／ポチ」）。よみの区切りは音を数えるためのもの。
