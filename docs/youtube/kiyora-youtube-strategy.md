# 気良歌舞伎 YouTube戦略 — 現状評価と令和8年公演までの方針

> 作成: 2026-08-16 ／ 前提: **令和8年9月26日（土）「曽根崎心中」初演まで残り6週間**
>
> 他団体比較（別途実施）を踏まえ、「何を作るか」より先に「今ある再生をどう団体名に変えるか」を定義する。

---

## 0. この文書の位置づけ

先行の他団体比較分析は、診断としては正しい。ただし2つの前提が抜けている。

| 抜けていた前提 | 実態 | 影響 |
|---|---|---|
| **公演カレンダー** | 6週間後に「曽根崎心中」**初演**。`docs/pr/pr-plan-r8-kera-sonezaki.md` に12週間PR計画があり、現在は Phase 2（役者紹介・カウントダウン）に入っている | 「過去映像だけで作る汎用3本」を今の最優先に置くと、公演連動の窓を逃す |
| **団体の自己定義** | 気良歌舞伎は自ら「**我々は歌舞伎保存会ではない**」と明言（`worker.js:222`）。2005年に地域活性化のため17年ぶりに復活、20〜50代の約40名 | 「保存会チャンネル内での順位」は本人たちの目的（地域を元気にする／自分たちも楽しむ）と噛み合わない比較軸 |

したがって本文書は、比較分析の**診断部分を採用し、処方箋と実行順序を差し替える**ものとする。

## 1. 現状診断

### 1-1. 数字の位置づけ

自前運営の地歌舞伎チャンネルとしては上位。年間約9.6万回再生は単独団体として良好。
ただし比較の読み方には注意が要る。

- 比較対象の登録者数は 20〜264人。**倍率（4倍・44倍）は絶対数が小さいため意味が薄い**
- ぎふ清流文化プラザは共同プラットフォームであり、団体単体との比較対象にならない
- 大鹿・小鹿野の強さは自前チャンネルではなく**チャンネル外**にある（後述）

### 1-2. 本当の課題 — ここが最重要

> **演目は見られているが、団体名が残っていない。**

- 流入の中心：「弁天小僧菊之助」「白浪五人男」「知らざぁ言って聞かせやしょう」
- 「気良歌舞伎」での指名検索：**年間15回程度**

これは制作量の問題ではない。**器（導線）の問題**である。
年9.6万回という流量は既にある。そこに団体名の受け皿が付いていないため、視聴が資産化していない。

新規3本を作っても、この構造を直さなければ「よく見られる無名の動画」が3本増えるだけになる。

### 1-3. 強みの正体

「超訳・名場面」フォーマットは他団体にほぼ存在しない独自資産。
公演記録は各団体が持っているが、**演目そのものを検索需要から捕まえに行っている団体は他にない**。
ここは維持どころか、シリーズとして固有名詞化すべき中核。

### 1-4. もう一つの資産 — 記録が一次資料になる

`research/jishibai/analysis/group_matrix.md` の悉皆調査によれば、全国94団体のうち **47団体が学術的言及ゼロ**。気良歌舞伎も「気良歌舞伎」「気良座」「気良」いずれも papers/books で0件。

つまり **気良歌舞伎について現存する記録は、自分たちが撮った映像しかない**。
これは「なぜ撮るのか」の最も強い根拠であり、対外説明（助成・行政・報道）でそのまま使える。

## 2. 他団体から学べること（比較の要約と補正）

| 団体 | 学ぶべき点 | 気良への適用可否 |
|---|---|---|
| **大鹿歌舞伎**（長野） | 認知の源はYouTubeではなく外部媒体。2017年3月、**地芝居として全国初**の国指定重要無形民俗文化財。映画『大鹿村騒動記』・南アルプス・道の駅と一体で「村へ行く理由」化 | 指定は模倣不可。ただし「行く理由」の設計＝郡上・明宝という文脈化は可能 |
| **小鹿野歌舞伎**（埼玉） | 町ぐるみの発信。屋台歌舞伎という映像的固有性。定期上演は年6回の祭礼奉演を含め**年十数回**（県指定は昭和50年・52年） | 上演回数では追えない。自治体連携は中期課題 |
| **小原歌舞伎**（愛知） | 最も再生された自前動画が公演ではなく**小学校の隈取教室**（約2,600回）。人と教育がコンテンツ | **最も再現性が高い**。気良にも稽古・手作りの大道具・化粧という素材がある |
| **中山農村歌舞伎**（香川・小豆島） | 茅葺き芝居小屋・棚田・奉納という映像的強度。英語字幕動画が検索上に存在 | 気良座（旧明方小学校講堂）＋郡上の風景で代替可能 |
| **横尾歌舞伎**（静岡） | 1〜2時間の記録性は高いが新規入口が弱い | **反面教師**。気良が戻ってはいけない形 |

**結論：** 気良が真似すべきは大鹿でも小鹿野でもなく、**小原の「人と教育」**と**中山の「風景と英語」**。
そして横尾のような公演記録一本足には戻らない。

## 3. 実行計画 — 3層に分ける

### Tier 0：導線工事（制作ゼロ・今週着手・6週間で効く）★最優先

既存の全動画に対する設定変更のみ。撮影も編集も不要で、**年9.6万回の既存流量に即日効く**。
1-2 の課題に直接効くのはここだけである。

| 施策 | 具体 | 狙い |
|---|---|---|
| **タイトル末尾に団体名** | `…知らざぁ言って聞かせやしょう【超訳】｜気良歌舞伎` | 検索結果一覧の時点で団体名が目に入る。指名検索の種 |
| **概要欄1行目を統一** | 「岐阜・郡上、明宝気良で受け継がれる地歌舞伎／気良歌舞伎」＋ 公式LP URL | 1行目は検索結果とサジェストに露出する |
| **冒頭3秒の名乗り** | 音声で「気良歌舞伎です」を入れる（新規分から） | 文字より音の方が団体名は残る |
| **終了画面（最後20秒）** | 次の超訳動画＋チャンネル登録ボタン | 回遊と登録転換 |
| **カード** | 超訳→該当演目の通し映像へ | 短尺から本編への送客 |
| **固定コメント** | 公演日時＋会場＋LP URL | 全動画が公演告知枠になる |
| **プレイリスト整理** | 「超訳シリーズ」「白浪五人男」「弁天小僧」など演目別 | 演目検索の流入を面で受ける |
| **チャンネルトレーラー** | 未登録者向けに60秒版を設置 | ここで初めて「気良歌舞伎とは」動画が生きる |

> 先行分析の「全動画に団体名を固定表示」という提案は正しい。ただし**画面表示だけでは検索とサジェストに効かない**ため、タイトル・概要欄1行目・音声の3点を必ず併せる。

### Tier 1：令和8年公演連動（〜9/26、6週間）

`docs/pr/pr-plan-r8-kera-sonezaki.md` のYouTube部分を、残り6週間で実行可能な形に絞る。

| 優先 | 本数 | 内容 | 根拠 |
|---|---|---|---|
| **1** | 1本（3分） | **「曽根崎心中」超訳** — 既存の勝ちフォーマット×新演目 | 検索需要（映画『国宝』文脈）＋公演の予習導線を1本で兼ねる。**最も費用対効果が高い** |
| **2** | 1本（3分） | **「二組のお初徳兵衛」** — 配役リレーのドキュメント | 中核役者→若手へ場を替えて継承。物語がそのまま素材。小原型「人」コンテンツの気良版 |
| **3** | 2〜3本（30秒） | 稽古密着ショート／カウントダウン | Tier 1 の1・2への予告編として使う。単独では主役にしない |
| **4** | 公演後 | **通し映像の公開** | 翌年以降の検索資産。1-4 の一次資料としての価値 |

**表現上の制約（PR計画より継承）**：心中物のため煽り表現と組み合わせない。若手挑戦は継承・成長の文脈で語り、優劣比較にしない。映画『国宝』は固有名詞の言及のみ（映像引用不可）。

### Tier 2：恒常資産（公演後・冬〜）

| 本数 | 内容 | 備考 |
|---|---|---|
| 1本（3分） | **「なぜ山里で歌舞伎を続けるのか」** | 130世帯の集落、2005年復活、大道具は座員の手作り、義太夫は他団体に依頼 — 素材は既にある |
| 1本（60〜90秒） | **英語字幕版 "Village Kabuki from Gujo, Japan"** | 郡上八幡のインバウンド動線に乗せる。公演後の映像を使えば質が上がるため、前倒ししない |

## 4. 自社資産との接続（YouTube単体で考えない）

この repo には既に配信基盤がある。YouTubeを孤立させるのは機会損失。

| 資産 | 接続方法 |
|---|---|
| `kabukiplus.com/kerakabuki`（公式LP） | 全動画の概要欄1行目からリンク。逆にLPへ最新動画を埋め込み |
| LINE Bot「気良歌舞伎ナビ」 | FAQに「動画で見る」導線。`next_performance` は更新済み |
| 演目ガイド NAVI | 超訳動画 → `kabukiplus.com/kabuki/navi/enmoku/sonezakisinju`（`sonezaki_shinju` もエイリアスで到達） |
| `note-articles/sonezakisinju.md` | 超訳動画の文字版として同時公開 |
| kabuki-post-365 | ショートの二次展開（Instagram / Facebook / X） |

## 5. KPI — 再生数を主指標にしない

気良歌舞伎の目的は「地域を元気にする」ことであり、再生数はその代理指標ですらない。

| 区分 | 指標 | 現在 | 目標 |
|---|---|---|---|
| **主** | 9/26公演の来場者数、うち「動画・SNSで知った」人の割合 | 未計測 | **当日受付で一言聞いて計測を開始する**（無料・予約不要のため受付カウント） |
| 副 | 「気良歌舞伎」指名検索の流入 | 年15回程度 | **月15回**（＝年12倍）を半年で |
| 副 | 登録者数 | 約1,058人 | 公演前後で1,300人 |
| 副 | 超訳動画からの登録転換率 | 未把握 | Tier 0 実施前後で比較 |
| 参考 | 総再生数 | 年9.6万回 | **目標を置かない**（流量は既に足りている） |

指名検索の増加が、1-2 の課題が解けたかどうかの唯一の答え合わせになる。

## 6. 推奨する位置づけ

> **日本一わかりやすい地歌舞伎チャンネル**
> 名台詞を超訳し、本編まで観られる山里の歌舞伎

競争軸は規模でも歴史の長さでもない。**「わかりやすさ」で入口を取り、「人」で記憶に残す**。
ショート／リールは主役にせず、この世界観へ呼び込む15〜30秒の予告編として扱う。

## 付録：先行分析からの差分

| 項目 | 先行分析 | 本方針 | 理由 |
|---|---|---|---|
| 最優先 | 過去映像で汎用3本 | **Tier 0の導線工事** | 制作ゼロで既存9.6万回に即効。課題1-2に直接効くのはここだけ |
| 公演の扱い | 言及なし | **6週間後の初演を軸に据える** | `docs/pr/` に12週間計画あり。窓を逃せない |
| 「気良歌舞伎とは」60秒 | 1本目に制作 | **チャンネルトレーラーとして後置** | 器（Tier 0）が無い状態では見られない |
| 英語版 | 初期3本に含む | **公演後** | 公演映像を使った方が質が上がる |
| 団体名の固定表示 | 画面表示 | **タイトル＋概要欄1行目＋音声名乗り** | 画面表示は検索・サジェストに効かない |
| 比較の枠組み | 保存会チャンネル順位 | 学ぶ相手を小原・中山に限定 | 気良は自ら「保存会ではない」と定義。順位は目的と無関係 |
| KPI | 再生数中心 | **来場者数と指名検索** | 目的は地域を元気にすること |
