## ブロック4
```
[gentle, serious Japanese narration] はんがんが、とじょうすると、かおよごぜんから、ふばこが届く。中に入っていたのは、もろのうの恋文への返事。一首の歌だった。「さなきだに、おもきがうえの、さよごろも。わがつまならぬ、つまなかさねそ」。超訳すると、「ただでさえ重たい、よぎの上に、夫でもないお方の、つままで、重ねてくださいますな」。「つま」は、着物のつまと、連れ合いの「つま」の、かけことば。夫のある身です、言い寄らないでください。古い歌を借りて、かどを立てずに、でも、はっきりと断ったんだ。もろのうは、恋が破れたと知る。そして、かおよが、夫に打ち明けたに違いない、と思い込むんだ。でもね、はんがんは、この手紙の中身を読んでいない。何も知らないんだよ。
```

## ブロック5

```
[friendly, serious Japanese narration] もろのうは、怒りを、はんがんにぶつけ始める。「おたくの奥方は、たいした、ていじょでいらっしゃる。字はお上手、器量もよし。せいぜい自慢なさるがいい」。「奥方のそばにべったりだから、とじょうも遅れるわけだ」。はんがんは、笑って受け流そうとする。「ご冗談ですか。それとも、お酒が入っておられるのか」。すると、もろのうは、その言葉を逆手に取る。「酒くさいのは、そっちだ。奥方と、さしつさされつ、それで遅れてきたのか。そんなに奥方が大事なら、明日から、お勤めに来なくてよろしい」。妻をからかわれ、役目まで取り上げるような言い方をされる。でも、はんがんには、なぜ責められているのか、まだ分からないんだ。
```

## ブロック9
