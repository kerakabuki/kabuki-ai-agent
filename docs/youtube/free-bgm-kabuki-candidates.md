# 「超訳！歌舞伎ナビ」用 歌舞伎らしいフリーBGM候補（2026-09-17調査）

用途: 気良歌舞伎チャンネルの演目解説動画（3〜4分）。共通BGMとして使い回す想定。
今回のきっかけ: 『盛綱陣屋』第4回（首実検・子どもの犠牲・無言の演技を扱う重い回）。

条件（必須）:
- 収益化済みYouTubeチャンネルで利用可
- トリミング・ループ・音量調整などの編集可
- Content ID（フィンガープリント）未登録・登録禁止
- クレジット表記の要否が明確

**注意:** 伝統曲の実演音源（三味線・鳴物などの生演奏）は曲自体の著作権が切れていても演奏者の著作隣接権が残るため、配布元が明示的に許諾しているものだけを候補にしている。以下はすべて配布元オリジナルの創作BGM（実演音源の権利処理済み配布物）。

## 3. 推し3曲

- **A1推し: 華志の舞（秋山裕和／H/MIX GALLERY）**
  三味線と笛が絡む和風感がもっとも強く、「勇壮」「楽しい」のムードタグが盛綱陣屋シリーズの他回（合戦・武将ものが多い）にも使い回しやすい。3:38と尺が長いのでタイトル用と締め用に別カットを切り出せる。収益化チャンネルでの無料利用が規約に明記されている点も安心材料。

- **B推し①: Moment（秋山裕和／H/MIX GALLERY）**
  「侍の別れ・決意」という文脈のムードタグが、首実検で小四郎が死を選ぶ場面・盛綱がその死を無駄にしないために嘘を選ぶ重さにそのまま合う。ナレーションを邪魔しない静かな構成で、ワンショット使用で3〜4分尺に収まりやすい。

- **B推し②: 津軽三味線独奏　貝殻節（伊藤ケイスケ／DOVA-SYNDROME）**
  三味線の独奏そのものであり、「歌舞伎の下座音楽らしさ」という点ではB系統内で最も直球。ゆったりしたテンポで無言の演技の場面の下地に向く。DOVA-SYNDROME（現OpenTracks）はクレジット任意・Content ID登録禁止の規約が明確で使いやすい。

## 規約上いちばん注意が要る点

1. **DOVA-SYNDROME（OpenTracks）は「作曲者が個別に条件を上書きできる」規約になっている。** 総則ではContent ID登録禁止・クレジット任意だが、曲の試聴ページに個別の注記がある場合はそちらが優先される。使用前に必ず該当曲のページを直接確認すること。
2. **魔王魂・MusMusはクレジット表記が必須。** 動画概要欄への記載を忘れると規約違反になる。
3. **H/MIX GALLERYは「通常のBGM利用」と「広告・放送・大型イベント等」で条件が分かれる。** YouTube動画（収益化含む）は無料利用の範囲内だが、番組宣伝やCM等に転用する場合は別途ライセンスが必要になる可能性がある。
4. **OtoLogicは規約原文を直接確認できなかった。** 拍子木・鼓などの単発効果音が欲しい場合は、規約確認が取れている効果音ラボ（Content ID登録禁止・収益化可・クレジット任意）を優先する方が安全。
5. **Pixabay Musicは配布元自体の規約は問題ないが、第三者からの誤Content ID申し立てが実際に起こり得る**とPixabay自身が案内している。今回の候補には含めていないが、今後使う場合は申し立て発生時の解除フロー（ライセンス証明書の提示）を把握してから使うこと。
