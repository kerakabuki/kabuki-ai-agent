# 名台詞リスト（「わかる！超訳」制作候補）

> 作成日: 2026-09-25
> 目的: チャンネル登録につながる「名台詞×超訳」（横長・1〜3分）の制作候補を、気良歌舞伎が演じて映像がある演目から選ぶ。
> 根拠: YouTubeの通常動画112本の再生数（2026-09-25取得）、YouTube検索の予測候補（同日取得）、`src/kera_archive_page.js` の公演記録。

## 1. 分かっていること

- 登録につながる入口は、有名な演目の名台詞で検索して来る人。いちばん当たったのは次の2本。
  - 【弁天小僧】浜松屋「知らざあ言って聞かせやしょう」（全編56分）: 5.7万回
  - 【わかる！超訳】弁天小僧「知らざぁ言って聞かせやしょう」（2分28秒）: 3.8万回
- 同じ「わかる！超訳」でも、台詞の知名度で再生数が大きく変わる（しがねえ恋の情けが仇 6,800回、ほかの白浪五人男の名乗り 1,300〜4,400回、寿曽我対面・蝙蝠安など 200〜800回）。
- 検索の予測候補に出てくるのは、多くの場合「台詞」ではなく「演目名」（熊谷陣屋 あらすじ、いがみの権太、封印切 など）。台詞そのものが検索されているのは「知らざあ言って聞かせやしょう」と「死ぬる覚悟が聞きたい」（映画『国宝』の影響）くらい。
- **題名は「演目名・役名」を先に、名台詞を続ける**のが、検索に掛かりやすい。

## 4. 作るときの決まり（当たった動画にならう）

1. 横長・1〜3分。台詞を字幕で出し、現代語訳（超訳）を添える。
2. 題名の型: `【わかる！超訳】役名「名台詞」｜演目名・場名　歌舞伎`。検索が弱い台詞は、演目名を先に置く。
3. 最後に「全編はこちら」で気良の公演の全編へつなぐ。全編の説明欄からも超訳へリンクする。
4. 演目ごとに再生リストを作る（例:「曽根崎心中 名台詞で観る」）。
5. 5.7万回と3.8万回の2本（知らざあ言って聞かせやしょう）に、固定コメントと終了画面でシリーズへの入口を置く。
6. 公開後1か月の再生数と登録者の増え方を記録し、当たった型を次に回す（YouTube Studio「チャンネル登録者（動画別）」）。
