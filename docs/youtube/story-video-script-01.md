## 設計方針

**原作の構造をそのまま骨格にする。** このエッセイは円環構造になっている。

- 冒頭「私はひとり席を離れ、そっと窓を開ける。神社の灯りが、にじんでいるようだった」
- 結末「私はひとり席を離れ、そっと窓を開ける。その先に——神社の灯りが、やわらかくにじんでいた」

さらに師匠の**「…稽古はいつからだ」**が、2005年（師匠→私たち）と2024年（私→息子たち）で反復する。
これが題の「螺旋」であり、**動画でも必ず残す**。台本を削るときも、この2箇所だけは触らない。

**拍子木が3回鳴る。** 幕開け（父の舞台）／再生（復活公演）／祝祭（こけら落とし）。
原作にある通り「キン………キン……キン…キン———」の間隔が詰まっていく。
**音の設計をこの3回に集中させる。**ナレーションを止め、拍子木だけを鳴らす。

**絵から写真へ、写真から映像へ。** 記録媒体の変化がそのまま時代の経過を表す。
これは演出ではなく史実の順序なので、時系列に忠実に並べるだけで機能する。

|---|---|
| 1940（昭和15） | 手彩色画のみ（写真なし） |
| 1950（昭和25） | モノクロ写真 |
| 2005〜（復活後） | SD映像 → HD → 4K |

## 制作上の判断メモ

### 音の設計

拍子木3回が背骨。**その前後は必ずナレーションを止めて無音にする。**
BGMを敷き続けると3回とも埋もれる。原作が文字で作っている「間」を、音で作り直す作業になる。

現在の効果音（拍子木・和太鼓）はライセンス不明のため、**KONTAKTの音源に差し替える**前提。

### 画質差をそのまま見せる

第3章の平成17年映像は720×480、第4章のこけら落としは4K。**この落差は隠さない。**
二十年が経ったことの、最も雄弁な証拠になる。無理に画質を揃えると意味が消える。

### 昭和25年から平成17年までの空白

素材が存在しない。だがこれは**「舞台が眠っていた時間」そのもの**なので、
黒画面や、眠っていた頃の講堂の姿で受ける。**ここをAI画像で埋めてはいけない**
（後述の区別を参照）。

### 生成画像（Gemini等）の可否

**原則: 記録が存在せず、かつ記録として提示しないところにだけ使う。**

| | 判断 | 理由 |
|---|---|---|
| 祖母・祖父・父の姿 | **不可** | 実在の人物。写真が無いなら「残っていない」と言えばよく、原作もそう書いている。そこに [絵] が効く |
| 気良の集落・気良座 | **不可** | 実在の場所。生成した「山あいの村」は気良ではない。訪ねた人の景色と違えば嘘になる |
| 芳名帳・受付 | **不可** | 記録の捏造にあたる |
| 高雄歌舞伎 | **不可** | 実在の他団体 |
| 昭和25〜平成17年の空白 | **不可** | 無いこと自体が内容。埋めると「その間も何かあった」という嘘になる |
| **江戸期の起源（1-2）** | **可** | 記録が最初から存在しない。現状は昭和25年の写真を当てているが時代が合っていない |
| **「芝居」の語源（1-3）** | **可** | 概念の説明。撮れるものが無く、イラストが最適 |
| **章間の転換・抽象** | **可** | 事実を主張しない |

**必須条件: 史料と見分けがつく絵柄にすること。**
[絵] は和紙の繊維も破れた縁も写った状態で入る。生成画像がこれに似た質感だと、
**視聴者がどちらが本物の史料か判別できなくなる**。
浮世絵調にするなら彩度と線を意図的に「きれいすぎる」方へ振る、
あるいはシルエット・単色の様式画にして写実から明確に離す。
**「これは想像で描いたものだ」と一目で分かる**状態を保つ。
