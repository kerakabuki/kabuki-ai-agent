## 生成したら確かめること

- [ ] 通しで聴く。特に名前の読み: 「かんぺい」（かんべい にならない）、「さだくろう」「やごろう」「よいちべえ」「なかぞう」
- [ ] 「ごじゅうりょう」が4つのブロック（1・5・7・8）で同じ読み・同じ調子か。ブロック5の最後の「……『ごじゅうりょう』」は、ひと呼吸おいて低く言えているか
- [ ] 「二つ玉」はテロップだけで、ナレーションでは読まない（読みの揺れを避けるため）
- [ ] ブロック5・6が明るすぎないか。明るければタグを `[whispering, slow, somber Japanese narration]` 寄りにする（暗くしすぎない）
- [ ] ブロック7（`[gentle, serious ...]`）からブロック8（明るい）へのつなぎが急すぎないか
- [ ] ブロック間で声の質が揺れたら、同じ日に続けて作り直す（v3 は生成ごとに揺れる）
- [ ] 使ったタグを台本本体 §8 の表に書き残す
- [ ] クレジットの見込み: 本文とタグで約1,870字。曽根崎心中（約1,580字・約3,400クレジット）の約1.2倍で、約4,000クレジット
