## 1. 結論

1. **中身は本物で、しかも希少。** 住民が自分たちの手で芝居小屋に変えた1937年築の木造講堂（郡上市指定重要文化財）、1986年以降の映像記録、日英2言語で全10話の復活ストーリー、5年ごとの座長襲名、若手が加わって約40名に増えた座組、地元ネタ。県内30余の地歌舞伎団体の中でも、語れる材料の厚さは上位にある。
2. **外から見える「証拠」と、それを載せる「器」が追いついていない。** 報道は2012年から地元紙が途切れずに取り上げており（中日新聞・岐阜新聞・朝日新聞・読売新聞・神社新報。Web記事10本と紙面スクラップ25件）、証拠そのものはある。ただしその多くはFacebookのアルバムにあるだけで、公式サイトからは見えていなかった。全国面・テレビの報道は見つからず、学術文献は0件、Wikipedia記事もない。観客数・フォロワー数・口コミといった第三者の数字も外に示せていない。器の面では、公式サイトをSNSで共有すると KABUKI PLUS+ の看板が出て、毎日のSNS投稿も気良歌舞伎の名前で KABUKI PLUS+ を宣伝する形になっている。会場と事務局の住所の書き分け、名称、英語表記は情報源ごとに揃っておらず、外部の紹介ページには古い会員数や旧Instagramが残っている。
3. **伸びしろは、新しい施策を足すことよりも、既にある資産を正しく揃え、数え、見せることにある。** 9/26 の公演は、QR記帳によって初めてブランドの基準値を取れる機会になる。

## 3. ブランドの自己定義（何を約束しているか）

| 要素 | 内容 | 出典 |
|---|---|---|
| 名称・読み | 気良歌舞伎（けらかぶき） | `src/kera_official_page.js`、県DB |
| 約束（ヒーロー） | 「山里に灯る、もうひとつの舞台。」 | `src/kera_official_page.js` |
| 信条 | 「守るために、変わる。」 | LP・PRESS・/project・README |
| 原点 | 「地域の人たちに元気になってほしい」「自分たちも一緒に楽しみたい」 | LP・PRESS |
| 成功の基準 | 「今年もよかったよ」——その一言がある限り、続けていく | LP・PRESS |
| 人格 | 素人が本気／客席と舞台が数メートル／笑い（地元ネタ）／祭り／無料・予約不要・堅苦しさなし | LP・観劇ガイド・note プロフィール |
| 象徴 | 灯り（灯し火）、菱に「氣」の紋と提灯、白浪五人男「稲瀬川勢揃い」 | ストーリー・`assets/kera-logo-gold.png`・`assets/photos/hero-kiraza.webp`・アーカイブ |
| 別系統のタグライン | 「素人歌舞伎の真髄がここにある」 | `worker.js:224`（団体データの初期値） |

**評価:** アイデンティティは明確で、言葉の水準も高い。「灯り」の主題はストーリーの序章から総括「灯し火の螺旋」まで通っており、実際の提灯（気良座入口の「気良座」提灯と紋入り提灯）とも結びついている。これは他団体がすぐには真似できない強みである。
弱点は、別系統のタグライン（「素人歌舞伎の真髄」）が団体データ側に残っていて、どの言葉を看板にするかの序列が決まっていないこと。**→ 2026-09-25 に事務局が、キャッチコピーを「山里に灯る、もうひとつの舞台。」に統一すると決定。団体データの初期値を差し替えた（コミット `140a42e`）。本番のGATEに出ていた「挑戦が、伝統になる。」（KVの値。キャッチフレーズと紹介文の最後の行）も、同日に事務局がGATEの編集画面で差し替え・削除し、公式トップ・GATE・団体一覧・共有時の説明文がそろったことを確認した。**

### 4-4 連想（思い浮かべてほしいこと・実際に浮かぶこと）

- 狙っている連想: 山里、灯り、近さ、笑い、無料、若い座組、家族三代、復活、自前の芝居小屋、新しいことに挑む一座。

### 4-5 ロイヤルティ（関係の深さ）

- **地域内:** 「僕も出たい」と言う子ども、秋に帰ってくる若者、市長の出演、103歳の祖母の来場など、関係の深さを示す物語は豊富。ただし数値はない【推定】。

### 避けたいこと

- 『国宝』は入口としてだけ使う。来場後に「気良」を覚えてもらう仕組み（記念カード、案内登録、便り）とセットでなければ、話題が気良のブランドに残らない。
- AI・NFTを看板の主役にしない。あくまで「守るための手段」として語る。
- 自動投稿の本数を増やすことで認知を取りにいかない。いまのデータでは、本数はリーチにつながっていない。
